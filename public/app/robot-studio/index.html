3. Export your EA

This is a real, editable MQL4 source-code starter strategy—not an EX4 binary or a completed WISDO server deployment.

Install & test

  1. Download the .mq4 file.
  2. Open MT4 → File → Open Data Folder → MQL4 → Experts.
  3. Place the file there and compile it in MetaEditor. Fix any compilation errors before testing.
  4. Use MT4 Strategy Tester and a demo account to evaluate different markets and conditions.
  5. Live deployment requires separate account permission, WISDO integration, and deliberate user confirmation.
