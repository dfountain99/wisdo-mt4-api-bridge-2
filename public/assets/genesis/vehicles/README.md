# Genesis aircraft asset upload location

Upload the file `abandoned_aircraft.glb` here, directly beside this README.
The path must be `public/assets/genesis/vehicles/abandoned_aircraft.glb`.

Use the **4.85 MB mobile preview** from the WISDO Genesis Aircraft Integration ZIP.

Before publishing, confirm that the asset creator permits redistribution.

Once the branch is deployed, verify the URL:
`/assets/genesis/vehicles/abandoned_aircraft.glb`

The client now automatically shows a static preview east of the player's
starting location; add `?aircraft=1` to the Genesis page URL to direct the
camera at the aircraft during quality assurance. Flight is not implemented.
