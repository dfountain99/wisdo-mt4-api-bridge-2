# WISDO Aether — exact-SHA certification lab

The lab is a separate infrastructure deployment. It does not change World Composition V2 PR #95. The static site contains only the Aurelia Prime fixture and the renderer files copied from the exact reviewed PR head. `WORLD_LAB_PR` and `WORLD_LAB_TARGET_SHA` (full 40 characters) are mandatory. The build fetches `refs/pull/<PR>/head` and refuses a mismatch. `build.json` exposes the PR, full commit, manifest version and SHA-256, renderer `aether`, and preview environment. A new PR commit requires a fresh deployment and invalidates old evidence.

For #95 set `WORLD_LAB_PR=95` and `WORLD_LAB_TARGET_SHA=691fe190bae57934d91ad27b41912f653b6c3536` on the separate `wisdo-world-lab` Render static service. Sync its Blueprint from this infrastructure branch, deploy it, and verify `/build.json` displays that exact SHA before inspecting the world. The service must be attached to the infrastructure branch, not the production API service. Do not copy production credentials, databases, payment, Discord, or MT4 configuration. The lab can be public because its fixture contains no account data. Only deploy the reviewed PR SHA; generated artifacts are excluded from git.

The static fixture proves rendering only. Authenticated Genesis/Forge needs an isolated PR web service with test login and database, no production secrets, and must independently display its running SHA. Never claim that the static lab proves the authenticated path. Save desktop and portrait golden and authenticated Forge screenshots, the persisted truth report, viewport sizes, review results, and the full SHA in an evidence directory. Then run `node scripts/checkAetherCertification.mjs evidence.json 95 <current-PR-head-SHA>`. The validator rejects missing captures, altered image hashes, nonpassing checks, and stale commits. Keep the evidence with the golden fixture or as a durable CI artifact, and revalidate against the current PR head immediately before merge.

WISDO-facing labels say **Aether**. Babylon.js API and dependency identifiers stay as they are. Aether certification remains pending until a human inspects the real render in desktop and portrait and the authenticated Forge preview has persisted observations.
