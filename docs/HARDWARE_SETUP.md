# Hardware setup

1. Install heatsinks and fan before closing the case.
2. Flash 64-bit Raspberry Pi OS Lite or Desktop.
3. Insert the microSD card.
4. Connect HDMI, keyboard, mouse, USB microphone, speaker, and Ethernet when available.
5. Power on only after the case and cooling are installed.
6. Run `scripts/first_boot.sh`, reboot, then `sudo scripts/install_pi.sh`.
