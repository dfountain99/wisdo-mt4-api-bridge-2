# Holographic Blueprint Renderer V1

The renderer makes creator intent visible before permanent world construction.

## Visual contract
Blue wireframe = proposed. Gold hologram = approved. Physical assets = forged. Structural prompts remain in Genesis until explicit approval.

## Live loop
Prompt -> preview compiler -> Idea Cloud -> preview operations -> Babylon holographic meshes -> architect/DNA save -> further revision. Preview operations are disposable and never become canonical World DNA merely because they rendered.

## V1 vocabulary
Theme, mountain range, forest, city zone, castle, ocean, river, landmass, space body and gameplay-module preview. The protocol is intentionally constrained and renderer-neutral.

## Expansion targets
Semantic placement and terrain surfaces; object handles; spatial pointing; planet/continent/city focus; layers/lenses; proposal diffs; branch compare; gold approval state; preview simulation; Forge button only after readiness; actual compiler-to-WOP forge transaction.
